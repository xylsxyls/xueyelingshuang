一、产品范围

PdfReader 是一个桌面 PDF 阅读和页面整理工具。旧版本位于 src/PdfReader_old，当前目标是保留旧版本可观察功能，并迁移到 Qt 工程及五端共享 Core 架构。

二、旧版本必须保留的功能

1. 打开和阅读 PDF

支持命令行打开首个 PDF 文件，也支持打开文件对话框。无密码文件直接打开；需要密码时反复提示，用户取消则取消本次打开。打开成功后显示页面缩略图列表和正文页面，页面使用 PDFium 渲染。

2. 页面查看和交互

左侧始终以单列显示按当前顺序排列的页面缩略图，扩大侧栏或改变窗口尺寸也不得换为多列。缩略图保留页面原始长宽比和颜色。右侧纵向显示正文页面。Ctrl 加滚轮调整缩略图条目背景或正文缩放：缩略图页图保持基准大小，条目增加灰色可点击背景并居中；正文范围为 25% 至 400%，步进 5%。点击缩略图或其灰色背景选择页面，并让右侧显示对应正文页；点击正文选择对应缩略图。两侧分别支持滚动，正文滚动进入下一页后，蓝色焦点和左侧缩略图选中项跟随当前可见页更新。打开新文件保留缩放但重置滚动和选择；打开失败或取消保留原视图。

缩略图按住页面500毫秒进入拖拽（由Config配置），立即在源页上方显示蓝色插入线，源页覆盖可透视PDF内容的浅蓝蒙层。首前、尾后及相邻页短距离移动均显示蓝线；指示与释放落点一致。拖拽时支持滚轮上下滚动和列表边缘自动滚动；按住Ctrl时也只滚动，非拖动态Ctrl滚轮仍缩放。释放后改变页面顺序，短按移动不重排；拖动期间始终只选源项，不能复制出第二个选中项。完成后选择跟随源页，正文内容与新页序一致；Esc、窗口失活及横向移出释放取消拖拽，原顺序不变。

3. 页面插入和保存

缩略图页面右键可在当前页前或后插入另一个 PDF，插入文件同样支持密码输入，成功后选择第一张插入页。左侧空白处右键可分页保存或按页码范围保存；页码范围支持逗号和闭区间，例如 3-5,7-8。

顶部提供打开、保存、另存为、最右侧蓝色问号、最小化、最大化/还原和关闭操作。保存沿用旧版本的覆盖确认、临时文件写入、替换原文件及失败提示；另存为支持 PDF 文件选择和覆盖提示。分页保存命名为 原文件名_001.pdf 等，先检查所有冲突再统一确认覆盖；取消时不能留下部分导出。页码范围作为选集按当前页序去重输出，非法范围应在选择输出文件之前报错。保存失败时原件保留，已生成的恢复文件给出路径。

4. 状态、错误和辅助界面

无文档时显示打开 PDF 的引导；打开、插入、保存、解析页码、密码错误、文件错误、取消和关闭均有可观察结果及错误提示。帮助窗口保留旧版本的功能说明，按钮悬停显示中文提示。

三、目标工程和平台

1. PdfReaderCore

PdfReaderCore 是五端共享的 C++11 核心库，目标平台为 Windows、Linux、macOS、Android 和 iOS。Core 禁止包含 Qt，使用 PdfEngine、CStringManager、CSystem 等跨平台二次开发库及其他已确认可移植依赖。Core 负责 PDF 文档和页面对象、当前页面顺序、打开/密码重试所需的非界面状态、页面尺寸/渲染请求、插入、重排、覆盖保存、另存为、分页保存和页码范围解析。

Core 同时提供 C++ API 和 C API。两套接口通过一个 PdfReaderCoreAPI.h 入口选择：调用方在首次包含前定义 PDFREADERCORE_USE_C_API 时使用纯 C 声明，否则使用 C++ 声明。C API 使用不透明句柄、固定布局结构体、枚举结果、UTF-8 路径、错误文本和调用方提供的位图缓冲区；实现层由 C++ Core 对象完成，C 边界捕获异常并转换为明确错误。Qt 工程必须定义该宏并只包含 PdfReaderCoreAPI.h，对接方式参考 LumaPlayer 的 LumaPlayerCoreBridge；纯 C 测试单元直接以 C 编译核对头文件和 ABI。

2. PdfReader

PdfReader 是 PC 端 Qt Widgets 应用，目标为 Windows、Linux 和 macOS。它只负责窗口、布局、绘制、缩略图和正文视图、滚动缩放、鼠标拖拽、菜单、文件/密码/帮助对话框、提示和平台界面适配，通过 PdfReaderCore API 完成功能，不复制核心 PDF 算法。

3. PdfReaderTest

PdfReaderTest 是 Qt 测试工程，包含核心 Core 的可判定测试和必要的测试界面。测试复用正式 Core API、真实入口和独立预期，覆盖成功、失败、取消、边界、页面顺序、保存结果及测试设施自身的错误识别。

四、构建和交付约束

默认 Release 使用 64 位和动态库。PdfReaderCore 的 version 脚本是编译 Core 本体，沿用现有本体构建入口；PdfReader 和 PdfReaderTest 的 version 脚本只准备依赖，需按依赖链使用 only 与 same，避免重复编译同一个库。Windows x64 Release 是本轮必测组合；Linux、macOS、Android、iOS 在工具和环境可用时验证，环境不可用时记录未验证。

五、验收依据

旧版本的每项可观察功能在 Qt 桌面界面中均有对应入口和结果；核心功能可在无 Qt 的 Core 中构建并由五端共享源码；Qt 工程不承担核心 PDF 状态和算法；PdfReaderTest 能独立判定核心功能及关键组合；版本脚本依赖顺序、位数、配置和动态库组合正确。未实际编译或运行的平台和配置必须在测试结果中明确标记为未验证。

图形界面控件使用 QtControls；缺少的封装在 QtControls 内按原有 ControlShow 等模板和 QSS 方式补充。提示、密码、范围输入、覆盖确认及文件选择交给 DialogManager 管理。布局、事件、定时器、图像等非控件类不额外封装。保持左侧单列居中、拖动唯一选择及点击定位正文的既有行为。
